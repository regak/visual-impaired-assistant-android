Methodology

Real transcriptions pulled directly from each HuggingFace source (not paraphrased) via pyarrow/parquet. Checked digraph/phoneme marker frequency, vocabulary diversity, and word-frequency skew as a domain-concentration proxy.

Key Finding

The ng' phoneme gap found earlier in AfriSpeech is NOT a universal Swahili ASR data problem — it's specific to that one corpus. FLEURS and w2v-bert-2.0 both contain genuine ng' words (ng'ombe=cow, ng'aa=shine) confirmed by context.

Recommendation

w2v-bert-2.0's underlying 400hr corpus (badrex/swahili-speech-400hr) is the most phonetically and topically balanced of the 3 accessible datasets — best candidate for future training/eval use in this app.
